# Codex Sidebar

Obsidian 侧栏插件, 使用 Windows 本机 Codex 登录. 桌面可直接启动隐藏 CLI, iPad 可连接 Windows 独立远程 Agent. 点击 Obsidian 工具栏的机器人图标, 打开或收起聊天栏.

[GitHub 源码仓库](https://github.com/xsoc1/obsidian-codex-sidebar)

iPad 默认收起“会话与连接”“上下文与学习”“模型与选项”和“提问与发送”, 为回答留出更多高度; 点开后保留原控件及选择. 学习工作台位于“上下文与学习”内, 写问题或停止回答请展开“提问与发送”. 若浏览器 Fetch 继续超时, 可在插件设置将“移动网络传输”改为“Obsidian 原生请求”, 然后保存并连接. 方式仅保存在当前设备, 不自动切换或重发. 原生请求超时后底层可能仍在进行, 先重连确认状态再决定后续操作.

0.6.2 包含移动入口与私有 HTTPS 远程桥. 每个配对设备使用独立隐藏进程、临时线程和会话记录, 与桌面本地聊天分开. 用户已确认 iPad 模型列表显示并收到实际短问题的完整回答, 前台基础对话通过真机验收. Windows 原生插件的远程对话、math-writing、补全、重连续聊与断线恢复另有验证; iPad 触控选区、补全、中文输入和后台恢复等仍待实测. 安装及连接步骤见 [iPad 使用指南](docs/ipad-setup.md), 迁移依据见 [可行性调研](docs/ipad-support-research.md). 新一次连接失败应按指南检查当前 iPad 路径; Safari 同样很慢时, 不能仅凭电脑端接口快速返回就认定已恢复.

## 使用

- 直接输入问题, Enter 发送, Shift+Enter 换行. 回复支持 Markdown 和数学公式, 可以停止或复制.
- 修改笔记: 捕获 Markdown 选区或源块, 输入明确修改要求; 发送按钮显示“生成修改预览”. 模型给出稿件后, 在回答中审核目标/范围/理由/差异并点“确认写入此文件”. “修改选项”可切换仅问答、明确改稿、整篇范围和原文类型. 源书摘录、教师原题与 PDF 只读. 不必进入学习工作台, 不给后台 CLI 写权限.
- 在侧栏回答中选中一段文字, 点击输入框上方的 `追问这段`, 再输入问题并发送. 引用卡片可检查或取消; 移动光标到输入框后引用仍保留. 追问附带所选文字及捕获时的原回答 Markdown, 保留公式, 不混入当前笔记选区. 切换会话会清除待发送引用.
- 在编辑、实时预览或阅读模式选中文字, 上下文卡片自动更新. 点击 `解释选区` 或 `检查证明` 会自动组织问题并发送.
- 点击 `捕获当前位置` 附带编辑光标附近或当前阅读视口的 Markdown. 卡片可展开检查源文本, 勾选是否附带到普通问题.
- `新会话` 创建独立会话. 下拉框切换本插件的历史会话. 隐藏 CLI 使用临时内存会话, 不加入 Codex GUI 的持久聊天列表; 聊天记录只保存在插件 `data.json`. 旧版插件创建的持久会话会归档, 原聊天文本保留.
- 用户消息上有 `编辑` 和 `重新发送`. 编辑后点击 `保存并重发`, 会从该问题之前的历史创建新分支, 保留原会话及后续回复. 新版消息保存原问题的源上下文或回答引用, 重发继续使用原快照. 旧消息缺少源快照时会提示并只重发原问题.
- `行内补全` 默认开启. 编辑停顿 1.2 秒后请求灰色建议, 不自动写入. 侧栏的 `待确认补全` 显示目标笔记与原始文本, 点击 `确认插入` 才写入; `取消` 或编辑器里的 Esc 丢弃建议. **Tab 保留 Obsidian 原生行为.** Ctrl+Alt+Space 可手动请求. 文档、光标或选区发生变化后旧建议失效.
- 补全是独立的隐藏临时请求, 不占用聊天轮次. 默认使用当前模型的 low 档次 (模型不支持 low 时使用模型默认档次), 自动请求会消耗 Codex 用量. 侧栏或设置可关闭, 设置中可调整等待时间. 最多读取光标前 6000 和后 2000 字符, 单次建议不超过 800 字符; 没有可靠建议时可返回空内容.
- 消息区下方持续显示 `思考中 / 正在回答 / 正在运行工具` 和耗时. 如果后端返回思考摘要, 可以展开查看.
- 输入框上方直接选择模型、思考档次及 `Fast`. 选项从本机 Codex 的 `model/list` 读取, 下一次发送生效, 回复进行中不可更改. 选择立即保存, 收起面板时再次保存, 重开或重载后恢复; 没有 `本机默认` 或另设默认模型的配置. 旧版空选择优先迁移为当前会话最近使用的模型和档次, 首次没有历史时由模型列表初始化一次. 已保存的模型若不可用会标明并要求重新选择.
- 侧栏各栏位不显示悬停说明, 聊天区域也不会弹出 `Codex 对话` 提示. 可见文字和屏幕阅读器标签保留.
- `Fast` 依据模型报告的服务档次发送请求, 关闭时显式请求标准速度. Fast 可能增加用量, 是否有访问权限由后端决定, 失败会显示错误.
- `上下文占用` 开关显示或隐藏后端最近一次请求的 token 数、窗口大小和占用估计. 显示的是最近请求, 不把整个会话累计消耗作为占用; 未报告窗口时不编造百分比, 重载后的历史值会保留.
- 默认工作提示词说明 Obsidian 阅读、解释、证明检查与研究任务, 要求公式使用 `$...$` 与 `$$...$$`, 保留 LaTeX, 并使用可直接复制到笔记的 Markdown. 同时注入实际 Windows 环境、vault、工作目录与 Obsidian CLI 路径, 说明 help 核对、显式 vault 定位、只读读取/搜索、客户端审核写回及插件诊断. 在插件设置中可以编辑或恢复默认, 修改后下一次发送更新当前会话. 完全未修改的旧版默认提示词会升级, 自定义内容保留; 固定注入只读工具与客户端确认写回的能力边界.
- 聊天与行内补全每次显式加载本机安装并启用的 `math-writing` 技能. 连接时用 `skills/list` 发现当前 vault 下的技能, 再以官方 `skill` 输入附带 `SKILL.md` 路径, 让后端注入完整技能说明; 不把整个参考包塞入每轮上下文. 侧栏显示就绪状态, 设置中的 `重新检查` 可刷新发现结果. 技能不存在或被禁用时明确报错并阻止本轮发送, 请先在本机 Codex 安装并启用技能. 插件不更改全局技能配置, 也不附带用户私有技能文件.
- 数学内容修改准则固定随请求注入, 自定义提示词仍保留: 题目可判断并明确标注补充条件; 已有完整过程的答案只做必要的最小修补, 保留路线、结构、符号和措辞; 错误大到需要重建时说明障碍与选择, 等用户决定后再改; 解题思路严格沿原路线展开. 语言依据本次原稿和用户提供的样本, 不套用技能示例作者的风格. 这些边界优先于技能通用的润色建议. 补全沿当前文本短续写, 遇到需要另换路线或等待用户决定的情形返回空建议.
- 后台助手可使用 `obsidian_cli_read` 只读工具, 由插件以参数数组执行当前 Obsidian CLI. 沙箱内直接 CLI 可能无法连接应用; 此工具固定当前 vault, 限制为帮助、版本、读取、搜索、链接、属性和 Base 查询, 拒绝任意 shell、eval、写入或其他 vault. 输出过长会标明截断.
- 设置里的 Codex 路径留空时从 PATH 查找 `codex.exe`. 路径更改后点击重连.

## 边界

- 0.8.0 处理 Markdown 笔记与有界 PDF 页来源, PDF 捕获不是原始 Markdown/LaTeX. 阅读选区携带对应的完整源块, 保留 LaTeX; 无法映射时标明 `渲染文本`. 不承诺精确源字符对应.
- 回答引用保存渲染选区 (最多 4000 字符) 与捕获时的原回答 Markdown (最多 24000 字符), 超长时明确标明截断. 选区不是精确源字符映射; 原 Markdown 用于核对公式和上下文.
- 自动捕获不自动发送. 快捷动作自动构造 prompt; 用户发送后才调用 Codex.
- 此插件运行自己的 Codex app-server 并复用登录. 历史列表为本插件创建的会话, 不直接接管 Codex 桌面应用正在运行的聊天.
- 桌面本地重连会新建临时线程, 恢复已保存的问答文本. 远程重连在桥进程存活时续接原临时线程; 桥重启后恢复问答到新临时线程. 内部工具输出及进程状态不会完整恢复. `data.json`、远程缓存与桥记录包含聊天和源上下文, 应视为私有资料; 临时会话不表示请求不发送给模型服务.
- 问答采用只读沙箱. 本地批准请求通过窗口显示, 远程使用 `approvalPolicy=never`, 不支持特权批准. 0.7.0 学习工作台的写回由当前客户端在预览、用户确认、原文版本复核后执行; 源书摘录和教师原题默认只读. Codex 进程没有新增写入权限.
- 收起面板保留连接与当前回复. 禁用插件或退出 Obsidian 关闭其本地子进程; 独立远程桥继续运行并保存回答.
- iPad 0.6.2 前台基础对话已通过此前真机验收; 0.7.0 原生请求已通过手机热点下的基础问答和重连恢复. 原 Wi-Fi 延迟原因、新版工作台/布局和其他移动交互仍待核验. 0.8.0 Windows PDF 离屏提取与模型页图识读已分别验证; 未验收 iPad PDF、全书 OCR、Canvas、手机及其他桌面操作系统.
- 思考摘要只展示后端实际返回的摘要. 没有摘要时仍显示思考状态, 不推测或伪造内部推理.

## 开发与安装

```powershell
git clone https://github.com/xsoc1/obsidian-codex-sidebar.git
cd obsidian-codex-sidebar
npm ci
npm run build
npm test
```

将 `manifest.json`, `main.js`, `main.js.map`, `styles.css` 复制到 vault 的 `.obsidian/plugins/codex-sidebar/`, 在社区插件中启用. 不覆盖已有 `data.json`.

远程桥构建产物为 `bridge.cjs`, 通过 `scripts/start-bridge.ps1` 独立隐藏启动. 服务配置、配对密钥和问答放在 vault 外的私有目录. 当前不会注册开机任务, Windows 重启后需重新启动桥. 不把这些私有文件加入插件包或同步到 iPad. 具体配置见上述使用指南.

仓库跟踪源码、测试与依赖锁文件. 构建产物、依赖目录、本机路径、环境文件及聊天记录不纳入版本控制.

协议参考: [Codex app-server](https://learn.chatgpt.com/docs/app-server), [Obsidian API](https://github.com/obsidianmd/obsidian-api).

工作提示词在创建临时会话时传入 `developerInstructions`, 并通过官方 `thread/inject_items` 以 developer 消息加入模型可见历史. 提示词发生变化或上下文压缩后再次注入, 保留 Codex 基础工具指令. 重连时同样通过公开注入接口恢复本地对话文本, 不使用标记为 Codex Cloud 专用的 resume history 字段. 不修改全局 Codex 配置或 vault 的 AGENTS.md. 本机协议需支持 `ephemeral` 和 `thread/inject_items`; 当前验收使用下述 CLI 版本. CodeMirror 模块由 Obsidian 提供, 构建不重复打包它们.

技能接入使用 [官方 app-server Skills 接口](https://learn.chatgpt.com/docs/app-server#skills): `skills/list` 只接受当前 vault 的发现结果, 选择已启用的 math-writing (优先用户安装版本). 每次 `turn/start` 的原问题/源上下文保持原样, 独立追加 `{type:"skill", name:"math-writing", path:...}`. 连接关闭或 `skills/changed` 通知使发现缓存失效. 自定义工作说明后始终附带用户修改准则; 补全另加短片段 JSON、无工具、无自行写入的任务约束.
