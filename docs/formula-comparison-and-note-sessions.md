# 0.11.0 公式对照与按笔记会话

本版为本地候选. 用户要求修复修改差异稿的 LaTeX 显示, 并先检查切换笔记能否检测, 以实现对应会话. Windows 原生检测已实际通过. 助手提出默认关闭/默认开启/只验证检测三种选择, 截至本记录没有收到答复; 在继续独立修复公式时, 已说明并采用可逆的默认关闭方案制作候选, 不把该默认值记为用户决定. 尚未覆盖日常插件或发布.

## 公式对照

普通聊天修改和学习工作台的待采用提案统一显示“修改对照 (公式排版)”, 分为“原文 (修改前)”与“拟采用稿 (修改后)”. 两侧保留完整 Markdown 数学块, 不把带 +/- 行标记的文本交给 MathJax. 若修改只覆盖公式中的一个字符, 显示范围扩到包含它的段落/数学块; 实际写回范围仍以宿主保存的字符范围为准, 展示扩大不扩大写入授权. 展开“查看原始字符差异”可核对精确源文及 +/- 行差异.

对照不修复、重写或双重转义数学源文. 不完整数学/代码边界、超过 80000 字符的展示上下文或不适合安全渲染的代码/嵌入保留源文. Markdown 排版在后台进行, 原始差异和确认控件不等待 MathJax; 排版失败保留源文并提示. 确认、去重、版本复验与安全撤销仍由原 ConfirmedWriter 执行.

## 按笔记切换会话

1. 打开“会话与连接”, 勾选“随笔记切换会话”. 默认关闭, 不给已有全局历史猜测归属. 若当前焦点在侧栏且尚未检测到笔记, 切回目标笔记一次.
2. 首次进入未关联的 Markdown/PDF 时新建一个本地会话; 返回同一路径时恢复对应会话. 同一文件重复事件、阅读/编辑模式切换以及聚焦聊天栏不会重复建会话. 自动切换不连接 CLI、不提交问题、不消耗模型请求; 真正提问继续复用原连接和会话历史.
3. 要复用旧会话, 手动从原会话下拉框选择它, 再点“将当前会话绑定此笔记”. 绑定会移走这个会话的其他路径关联, 不合并或删改聊天内容. 开启功能后点“新会话”会将新会话用于当前笔记, 旧会话仍留在列表.
4. 回复、准备请求、写回/撤销、学习作答、回答引用、输入草稿或编辑已发消息期间暂缓切换, 显示等待原因并只保留最新目标. 发送/清空草稿、取消引用/消息编辑或任务完成后继续. 期间当前快照不被新文件事件悄悄替换; 真正切换后清除旧当前快照, 按原“自动捕获”设置取得新来源. 关闭自动捕获时不会因此读取新正文.
5. 手动选择其他历史或重发分支会暂时保留手动会话, 不被刷新抢回. 下次换到另一笔记恢复跟随; 也可关闭再开启跟随. 关联不改变旧任务/原上下文的重发语义. 固定伴读来源仍保持固定, 不随会话更换; 检查工作台来源标签后再发起任务.
6. 原生重命名/移动事件迁移路径关联并保留会话 ID. 若新路径已有其他关联则提示冲突, 不混合两个历史, 需显式选择再绑定. 删除笔记只移除关联, 聊天历史保留. 本功能不创建后台复习任务、不扫描全库、不替用户改正文.

关联为设备本地 `codex-sidebar-note-sessions:v1:<vault>:<scope>`, schemaVersion=1, 保存 Enabled 和 Path/SessionId 关联. 桌面 scope 为 desktop, 远程为当前设备的 remote CacheId; 不含配对密钥, 不写入远程 State、学习记录或笔记 frontmatter. 最多 2000 条、约 100 万字符 JSON, 损坏/未知 schema 原样保留并显示错误. 连接桥时保留本地已关联但尚未同步的会话, 避免旧服务端状态覆盖刚建立的对应会话; 已有同 ID 服务端历史仍沿原协议处理, 不引入通用冲突合并器.

回退只恢复原四个插件构建文件. 旧版忽略关联表, 新建的会话仍是兼容的普通会话, 可手动选择. 修改/学习记录 schema 未变, 不删除新产生的历史或记录. 开关只停用跟随, 不清空映射或历史; 标准插件数据和配对配置继续分别保留.
