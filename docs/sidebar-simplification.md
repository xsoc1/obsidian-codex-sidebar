# 侧栏精简与工作台移除

0.16.0, 2026-10-25. 用户已明确授权 Windows 安装与 GitHub 发布. Windows 安装及原生界面核对已完成, [GitHub/BRAT 预发布](https://github.com/xsoc1/obsidian-codex-sidebar/releases/tag/0.16.0)、CI 和公共资产回读均已完成; 实际进度与验证记录见 [版本说明](releases/0.16.0.md).

## 使用变化

侧栏不再显示会话区下方的笔记路径和“笔记对应会话”提示行. 会话标题、历史下拉框、新会话、重连与手动绑定入口保留. 四个折叠区为“会话与连接”“上下文”“模型与选项”“提问与发送”, 保留已有开合状态.

“随笔记切换会话”移至 Obsidian 的设置 → Codex Sidebar. 开关继续读取原设备的值和路径关联, 不重新初始化, 仍区分本机与独立远程连接. 未设置过时默认开启. 关闭只暂停自动切换, 不删除原会话或关联; 回复、草稿、引用和写回期间仍延后切换.

“修改范围”也移至插件设置, 三个选择不变: AI 自选当前笔记范围、严格选区/捕获块、当前整篇笔记. 新选择保存到当前连接模式的设置, 重载后恢复. 远程重连优先使用当前客户端缓存中的范围, 不被桥返回的旧 AI 自选或缺失字段覆盖; 没有客户端范围时默认 AI 自选. 范围设置只影响下一次新修改请求, 不改变已保存提案或旧任务重发使用的原范围. “随笔记切换会话”设置开关不再因打开设置时恰逢笔记切换而持续禁用; 开关状态继续由原关联模块保存.

输入区保留“提问”“生成修改预览”和“停止”. Enter 提问, Shift+Enter 换行, 原生 Tab 和 IME 行为保留. 修改仍由 AI 辨识片段角色, 完整答案最小修补、思路沿原路线展开, 审核差异后才由当前客户端写入. 生成预览不等于已经修改笔记.

## 移除范围与旧数据

数学学习工作台已移除, 包括固定/跟随伴读面板、结构化练习、分级提示、尝试反馈、学习记录管理、主动复习、课程清单、样章/章节流程、工作台修改提案及 Markdown/LaTeX 导出. 相关任务不再生成、注册、消费或重发; 不再监听学习记录的正文版本变化, 也不再因学习作答区暂停补全.

普通聊天中的解释、检查证明、回答选段追问、PDF 提问、行内补全及聊天修改提案仍可用. 共用的源版本、数学差异展示、宿主确认写回与安全撤销移到 `src/edit`, 并未随工作台删除. 模型和技能协议、远程只读权限及设备隔离保持原有边界.

已有聊天中的 TaskSpec、原问题、原 Prompt、源快照和回答继续保留. 旧工作台输出可以查看或复制, 但不能重新运行其流程或恢复其写入能力. 普通聊天与 `Action=edit` 的分支重发仍使用原任务/来源; 当前文件选择和范围设置不覆盖旧快照.

旧 `codex-sidebar-study:v1:<vault-name>` 设备记录原样留存, 新版既不读取也不写入或删除. `.study.json` 不再加载, 旧的课程只读单元标记也不再生效. 需要确定性只读保护的材料应使用笔记 frontmatter `codex-readonly: true`, 或 `study-role`/`role`/`note_type` 的 `source-excerpt`、`teacher-problem` 值. 普通 Markdown 正文不受功能移除影响. 移除功能不等于删除用户的历史记录或课程文件.

## 安装、回退与验证边界

用户已明确授权本次安装与发布. 更新时仅替换 `manifest.json`、`main.js`、`main.js.map`、`styles.css`, 保留 `data.json`、远程缓存、设备存储、图片缓存与配对信息. 本改动兼容已有远程桥, 无需更改登录或权限.

回退时恢复同一备份的四个插件文件, 不整份回灌旧会话数据. 原工作台数据仍在时, 支持它的旧版本可以继续读取; 这不自动撤销已采用的笔记修改. 新设置可能被旧版忽略, 重新升级后保留值. 已有修改提案的确认与撤销仍需通过当前源版本检查.

测试分别检查模块安全规则、实际构建入口的设置/历史兼容和浏览器布局. 这些结果不能替代真实模型请求、Windows 原生交互、手工中文 IME 或 iPad 真机验收; 本候选的已完成与未完成检查只以版本记录为准.
