# 追问后整合原说明

0.14.0 候选版沿用回答选区入口: 在助手回答中选中内容, 点 `追问这段`, 输入疑问后点 `提问` 或按 Enter. 新回复先解释疑点, 再把解释放回原来的逻辑位置, 从起点到结论完整重述原说明. 第二部分可独立阅读, 保留选段前后的有效内容、公式、条件与原有证明路线. 明确要求“只解释这里, 不要重述”时, 以本轮要求为准.

例如原说明依次介绍范数距离、反三角不等式、连续性和 Cauchy 列. 针对“交换两个向量后为何得到绝对值”追问, 回复既说明双侧估计如何合成绝对值, 也把这一步接回距离到连续性与 Cauchy 结论的完整叙述.

生成的是一条新回答. 原回答与历史保留, 笔记不变; `生成修改预览` 仍需单独捕获笔记来源, 并在确认后写回. 完整答案的数学错误仍按最小修补处理, 必须重建证明时先交用户决定. 解释的整合不是任意换路线或重写其他答案的授权.

## 快照与兼容

- 引用仍保存渲染选段及原回答 Markdown, 不声称两者有精确字符映射. 选段上限 4,000 字符, 原回答上限 24,000 字符.
- 原回答截断、尚在生成、已中断/失败或只是过程消息时, 后一部分标为 `已捕获部分的整合说明`, 说明不完整, 不猜测缺失后文. 长回答尾部选段可能不在原文前缀中, 不拼造其前后逻辑. 旧回答未知完成状态保持 unknown.
- 固定引用后保留当时的内容和完成状态, 即使原回答后来继续生成也不静默更换. 要使用新全文需重新选择并引用.
- 新引用带 `FollowupMode: integrated-v1` 和宿主产生的 `SourceStatus`. 新回复的实际 Prompt 与快照一起保存. 重连使用已保存 Prompt, 修改并重发使用原引用、原模式与新问题, 不换成当前笔记.
- 旧引用无模式字段时, 重发仍使用旧的局部解释规则. 对任何旧回答重新选择 `追问这段` 即可采用新版. 不迁移或重写原历史.
- 仍使用 `text + math-writing skill` 两项输入, 没有第三个技能项或新增工具权限. 客户端生成提示, 现有远程桥无需重启或替换. 配对设备、学习/编辑存储与模型选择不变.
