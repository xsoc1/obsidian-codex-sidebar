# 数学表达更新

本专项让解释、讲义、反馈和修改理由围绕具体数学内容展开。必要的条件、反例、来源和真实缺口保留；重复担保、流程复述和统一免责声明不再作为默认模板。完整讲义仍交付定义、首次计算与主要证明。

0.12.0 经用户明确授权安装到 Windows 日常插件，并已完成 GitHub/BRAT 预发布及六件资产校验。发布后用户另行授权采用私有技能 `0.3.0-candidate.4`，本机已备份、安装并由 Windows 侧栏实际重新发现。在用远程桥未重启。真实结果与未验收项见 [验证记录](math-exposition-validation.md) 和 [发布记录](releases/0.12.0.md)。

## 使用

当前使用普通聊天及“生成修改预览”。解释请求直接解释；修改请求先生成差异预览，再由用户确认采用。0.16.0 已移除学习工作台，历史任务保留只读；本页的 0.12.0 部署证据属于历史版本。可明确说“只调整这段语言，保留条件、公式、编号和原证明路线”。完整答案的普通修补仍采用最小改动；根本错误需要先决定处理路线。

文风调整沿用已有修改 TaskSpec，不增加任务 schema 字段。点击“提问”始终问答；点击“生成修改预览”才进入改稿，输入措辞不自动切换行为。教师题、来源摘录和 PDF 默认只读。讲义草稿可在普通聊天中请求，但已无工作台样章、章节推进或自动新建文件流程。

## 规则与任务字段

- `src/exposition/rules.ts` 是表达策略的单一入口。通用规则随工作说明加载，任务模板只加对应的短策略，补全使用独立短策略。
- `src/edit/rules.ts` 保留用户的数学修改规则，并明确语言修改授权与数学修正的区别。`edit/protocol.ts` 的理由示例使用具体改动，继续保留 `needs-decision / no-change`。
- 普通聊天返回 Markdown，笔记修改保留严格的 `note-edit` 输出契约。旧反馈、样章、章节等结构化任务已移除，只保留历史；当前运行时不再生成或执行这些工作台任务。
- 没有正则删句、流式重写或自动二次润色请求。显示、保存和导出继续使用原有正文及状态分工。

## 默认、自定义与历史

`src/exposition/legacy.ts` 冻结旧完整默认文本，仅供精确迁移。已知未改默认升级，自定义正文逐字保留，包括空白、引用和看似旧规则的内容。用户自定义中若含旧限制，不自动删除或假装语义冲突已消除；可由用户在设置中明确修改或恢复默认。

托管规则仅识别完整、精确的结尾片段；不会按宽泛标记删除用户文字。重复组装不累加同一托管结尾。重连或压缩后的再次注入照常进行，现有指令哈希因新规则变化而刷新。

旧消息、已存 Prompt、回答引用和来源快照保持原样。普通聊天和修改重发复制原任务与来源；旧工作台任务拒绝重发，重新捕获仍是另一动作。规则版本出现在托管说明中；旧生成记录的版本不追填。

## 远程桥与混合版本

新客户端远程工作说明不再自报 Windows 环境。桥端在启动和 developer 注入时补入实际环境，并保证自有完整规则在末尾；用户/assistant 历史保持原文。客户端与桥端都更新时，同一有效组装只有一个托管规则块。

不把客户端声称的环境或权限当成服务端事实。旧客户端中的旧环境文本保留为其输入，桥端实际环境后置；固定工具白名单、只读沙箱与 `approvalPolicy=never` 继续由代码约束。普通输入仍是 text+math-writing，PDF 继续允许最多两个受管图片，没有第三个 skill 或任意客户端技能路径。

新旧客户端/桥端的传输契约保持兼容。旧桥会附加旧规则，因此未同时升级和实测前，不能宣称文风一致。更新候选桥不等于允许重启在用服务。

## 私有技能候选

私有 `math-writing` 候选单独交付，不进入公开源码或插件 ZIP。它在原 0.2.0 的基础上整理表达与按需路由，增加具体例子和 UTF-8 参考文件读取方法。候选阶段未改全局安装；后续经明确授权，已备份原 56 个文件并更新六件新增/变化文件，安装后的 59 文件树与已验证 candidate.4 逐字节一致。Windows 侧栏通过 `skills/list forceReload` 识别新版，聊天、来源、UI 和设备状态保持不变；此步骤没有新增模型推理或 iPad 验收。

Windows PowerShell 经管道读取中文时，需要同时处理文件解码与管道输出编码。候选技能和实际环境说明给出只作用于当前读取进程的方法；不改 PowerShell profile、系统区域或全局 Codex 配置。

生产选择器仍优先启用的用户级技能。评测脚本只在自有测试根下选择 `skills/list` 实际发现的对应路径，并记录版本、文件树摘要和请求配置。这个测试入口不会改变生产选择器或桥端技能校验。

## 复现与回退

常规检查沿用 `npm run build`、`npm test`。原创输入在 `examples/exposition/cases.ts`，评分条件单独放在 `tests/fixtures/exposition-rubric.json`，不会拼入请求。`scripts/exposition-live.ts` 是显式启动的真实对照脚本，默认只发现技能，不发送推理请求；参数和预算见验证记录。

插件安装发布与后续私有技能采用是两次明确授权，均未重启在用桥。插件安装只替换 manifest/main/map/styles 四件资产，技能更新另有独立完整备份；保留聊天、配对和学习数据。技能回退只处理此次变化且没有后续改动的文件，冲突时先合并。撤回插件代码不会撤回已生成的历史内容。恢复设置只处理本专项实际迁移、且此后没有被用户修改的字段；冲突时保留现值。不要整份回灌旧 data.json。
