# 会话删除与验证

## 使用

展开侧栏“会话与连接”, 从下拉框选择会话, 点击“删除会话”. 核对会话名称与消息数量后确认. 取消不写数据; 删除没有插件内撤销入口.

删除只针对选中的会话. 其他会话和重发分支保留, 已采用的笔记修改和设备本地修改记录也保留. 若删除的是当前笔记的自动关联会话, 为该笔记创建一个新的空会话. 删除其他旧笔记的关联后, 下次打开该笔记会生成新会话. 删除最后一个会话也会留下一个空会话.

## 保存和并发

`src/sessions.ts` 负责可测试的删除计划与恢复规则. 确认框绑定会话 ID、标题与完整消息内容; 确认时原内容已变化则拒绝, 不猜测要删除的目标. 回复、连接、笔记切换、写回/撤销、未发送草稿或回答引用会阻止删除. 删除保存期间禁用会话与发送控件, 同一确认只提交一次.

删除计划先进入原有设备保存队列, 成功后才更换内存状态、移除关联和显示缓存. 保存失败时原会话及关联不变. 排队的其他保存重新读取当前状态, 不会将删除前的快照写回来. 被删会话的迟到显示结果失效, 其他会话的渲染缓存保持有效.

桌面数据仍在插件的 `data.json`, 远程使用原有配对设备缓存. 新增可选的 `DeletedSessionIds` 字段, 旧数据无需转换. 标记合并于插件自有的 `/state` 状态, 不新增 Codex RPC、客户端技能路径或输入类型. 重连时合并本机/远程删除标记, 防止旧远程状态恢复已删会话. 本机保存成功但远程同步失败会单独提示; 下次重连保留本机删除结果. 设备作用域延续原有隔离, 不跨桌面/配对设备删除.

此功能移除插件保存及显示的对应聊天记录, 不承诺清除 Codex 服务既有模型上下文、操作系统备份或另行导出的记录. 不通过未经核对的后台删除接口实现安全擦除. 独立修改记录仍包含恢复/安全撤销需要的原文; 如需清除此类记录, 使用设置中的独立导出和清除操作.

## 升级与回退

正常升级保留 `data.json`、配对设备缓存和修改数据库. 安装前备份这类设备数据, 不将其提交到 Git. 不读取或修改旧学习工作台数据.

旧版本不识别删除标记, 回退前应备份当前数据并断开远程连接, 避免旧远程快照恢复已删记录. 不通过清空历史或恢复旧整份状态来回退代码. 此版本不需要重启或更新 Windows 远程桥.
