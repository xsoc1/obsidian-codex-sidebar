# 数学学习工作台 (0.7.0 实验版)

> 历史归档: 数学学习工作台在 0.16.0 已移除. 本文只记录旧版本设计/使用/验证, 不是当前功能指南. 旧学习记录原样保留, 新版不读写; 迁移与回退见 [侧栏精简说明](sidebar-simplification.md). 旧脚本和示范清单可在 [0.15.1 源码](https://github.com/xsoc1/obsidian-codex-sidebar/tree/0.15.1) 查看, 当前源码不再提供这些执行入口.

工作台在原 Codex 侧栏的“数学学习工作台”中, 复用原模型选择、会话、引用和重发. iPad 先点开“上下文与学习”, 再展开工作台; 普通聊天时上下控件默认收起. 构建本身不会更新日常插件或远程服务; GitHub/BRAT 使用预发布 0.7.0.

## 伴读与一题一练

1. 在正文选择一段, 展开工作台, 查看路径、映射、捕获时间和截断提示. “固定本段”保存快照, 焦点变化不换目标. “跟随当前位置”解除固定; “重新捕获”明确更换快照.
2. 选择解释本段、说明符号、展开这一步或检查论证. 解释直接给出, 不要求先回答问题. “来源清单与输入角色”区分题目、完整答案、思路和讲义; 未分类材料默认只读.
3. 相近练习从完整正文派生一道题, 提示逐层揭示. 可以直接查看完整答案; 解答缺失时该动作发起明确的完整解答请求.
4. “我的尝试”聚焦时取消在途补全、清除灰字并暂停新请求; 离开后恢复原开关, 不绑定 Tab. 提交后反馈允许其他正确路线, 不确定则标 uncertain. AI 反馈不是独立数学核验.
5. 返回正文回到此题来源. 复习由用户主动进入, 不注册后台任务, 不报告掌握百分比.

原始结构化输出保留在会话, 默认折叠以免提前展开提示/答案. 明确查看或复制原始输出也记作揭示. 编辑反馈并重发会创建新尝试, 原尝试与反馈保留.

## 可选课程清单

旧笔记没有清单也可以伴读与临时练习. 可将 [历史示范文件](https://github.com/xsoc1/obsidian-codex-sidebar/blob/0.15.1/examples/study/demo.study.json) 和同目录两篇原创讲义复制到独立测试 vault 根目录, 填入 demo.study.json 加载. 清单关联课程、标题单元、直接前置、来源和稳定练习 ID. 解答保留 unverified; 来源 user-checked 仅表示用户登记核对.

勾选直接前置才补读清单中最多三段, 每段不超过 4000 字符, 不搜索/上传整个 vault. 同 ID 的历史尝试不因重新加载覆盖; 题目内容或正文版本变化会标记变化, 不用旧尝试认证新题.

首版可写单元从一个 Markdown 标题开始, 到下一标题前独立一行的末尾块 ID 结束. 中间可有公式、callout 和其他唯一块 ID. 末尾锚点后仍有正文、ID 重复或位于代码/公式中时拒绝定位. 普通段落块仍可伴读, 不自动扩大为整个标题单元的写权限.

## 样章与待审修订

1. 固定来源, 填写来源、终点、先修/运算熟练度、主线、原内容去向和新稿路径. 目标为当前客户端 vault 内 Markdown, 父目录须存在.
2. 先生成一节完整样章: 定义/条件、首次运算、主要证明和必要依赖在正文完成, 不固定挖空. 检查目标、版本、差异与渲染稿.
3. 审核后点击确认采用. 确认前无正文写入; 确认时再次核对未落盘编辑器/文件, 写一次并回读. iPad 使用 iPad Obsidian API, Windows Codex 保持只读.
4. 确认样章组织与确认文件写入分别进行. 之后更换新稿路径, 每次生成下一节新文件. 改变来源、终点、主线或内容去向会取消旧样章批准; 继续默认沿用已确认样章的原来源快照.
5. 待审补充需明确缺口、单元 ID、插入/替换范围. 只有讲义角色允许提案; 清单中的源书/教师原题始终只读. 完整答案保留最小改动, 思路沿原路线, 重大重建交用户决定.
6. 陈旧预览拒绝采用, 重新捕获后再生成, 不自动覆盖后续编辑. 重复点击去重; pending 写入重启后通过回读判断是否已完成, 恢复仍需确认. 安全撤销要求当前内容完全等于采用结果, 后续编辑存在则拒绝. 新建文件不自动删除.

路径、SHA-256 和范围由宿主产生. 模型只给内容与理由; 格式通过不等于数学正确、来源已核验或用户已批准.

## 数据、导出与迁移

学习数据使用设备本地 localStorage 的独立 codex-sidebar-study:v1:<vault-name> 项, 含 schemaVersion、随机设备 ID、快照、任务、练习、尝试、提示/答案揭示与写回收据. 不进入 data.json/整份远程聊天覆盖, 不默认同步或合并设备. 同名 vault 在同一存储域中共用该项, 请用不同 vault 名称隔离. localStorage 不加密, 容量不足会显式失败.

可导出学习 JSON, 不提供自动导入/跨设备合并. 清除需要输入“清除”, 移除内容及写回基线, 仅留已消费任务 ID 防止迟到回复复活. 原聊天与正文保留; 清除后旧写作重发不恢复写权限.

阅读 Markdown 完整保留正文. 练习导出可附提示/解答, 不含学生尝试. LaTeX 源码支持标题、段落、简单列表、callout、稳定标签、普通 wikilink 显示文字和行内/独立行行间公式; 表格、图像、代码、HTML、可执行 TeX 指令拒绝导出. 不承诺任意 Markdown 无损转换, 不运行编译. 移动 WebView 下载行为尚待 iPad 真机验收.

0.6.2 的原设置/聊天兼容, 新增字段均可选. 没有任务元数据的旧消息沿用原流程. 未知或损坏学习 schema 保留原始项并报错, 兼容本轮早期 SchemaVersion 字段名称, 但不推测转换其他非空旧学习 schema.

回退前导出学习记录, 保留 data.json 与远程缓存, 仅恢复旧构建文件. 普通讲义/已确认新稿仍可阅读; 旧版忽略学习存储. 回退不自动逆转已审核正文. 新桥完成标记用于结构化任务断线恢复, 发布时应配套更新桥; 本轮未部署日常服务.

## 验证

见 [协议/技能](study-protocol.md) 和 [实际验证](study-validation.md). npm run build 和 npm test 不调用模型. 两个 opt-in 实测脚本需设置 CODEX_STUDY_TEST_CLI, 复用登录但不读认证文件, 只在新临时目录使用原创样本:

~~~powershell
npx tsx scripts/study-live.ts
npx tsx scripts/study-remote-live.ts
~~~

前者的写入宿主是内存 fixture, 后者为独立测试桥与真实 app-server. 原生写回另在临时 Obsidian vault 执行, 不能用模拟宿主冒充.
