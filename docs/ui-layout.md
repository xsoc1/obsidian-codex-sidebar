# 侧栏阅读布局

0.15.0 采用更紧凑的控制区和更开阔的回答区. 用户提问保留浅底卡片, 助手正文使用细分隔线; 正文字号随 Obsidian 文本字号变化, 桌面至少 14px, 移动端至少 15px. 输入区保留“提问”“生成修改预览”和“停止”, 长标签可换行. 当侧栏内容宽度不超过 300px, 模型/思考档次纵向排列, 上下文操作分为两列. 公式、代码和表格超宽时在正文内部滚动.

四个折叠区仍是“会话与连接”“上下文与学习”“模型与选项”“提问与发送”. 点击标签即可开合, 原设备保存的开合状态继续生效. 上下控制区收起后扩大阅读区域; 追问仍沿既有行为展开输入区. 键盘焦点有可见描边, 不增加悬停说明. Enter 提问、Shift+Enter 换行、原生 Tab 和中文输入法处理沿用既有实现.

本版仅调整样式, 不迁移聊天或设备数据. 保留固定上下文、引用重发、修改确认、原生工具权限与独立远程桥. 桌面和移动客户端更新即可采用新布局, 在用远程桥无需重启. 如需回退, 备份当前插件数据, 安装上一版本的四件插件资产并重载; 不删除 data.json 或设备存储.

## 验证方法和边界

- `npm run build` 和 `npm test`: TypeScript/esbuild 与 127 项既有功能测试通过.
- `node scripts/check-sidebar-layout.mjs`: 需要 `CODEX_LAYOUT_BROWSER` 和公共 `CODEX_LAYOUT_APP_CSS`. 保留原 12 个检查, 增加与不可变 0.14.0 样式同 DOM 对照的 16 个场景: 240/320/450/612px、明暗主题、桌面/移动布局. 回答正文宽度增加 18px; 控制区折叠时桌面阅读高度增加 34.375px、移动增加 4.375px. 检查按钮全文、忙闲状态下停止位置、全部展开后的操作可达性、长内容局部滚动、键盘焦点、减少动画、草稿/选区和折叠恢复. 这些数字来自固定 fixture, 不是所有主题或 iPad 真机的统一收益.
- `node scripts/check-stream-layout.mjs`: 实际 CodexView 与异步 SDK fixture 的 24 个流式场景、4 个上下文场景通过. 保留消息节点复用、阅读锚点和非平滑滚动; 不添加高度/位移动画.
- Headless 截图使用原创矩阵交换子例子, 已抽查深色桌面与浅色窄栏. 数学长内容 fixture 不是原生 MathJax, 键盘事件不是手工中文输入法验收. 没有追加真实模型请求或 iPad 真机测试.

Windows 安装和 GitHub 发布只在实际完成并回读后写入版本说明. 原始截图、会话备份和部署收据留在 Git 之外.
