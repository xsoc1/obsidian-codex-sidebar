# PDF 伴读与区域放大

适用 `2.0.0-beta.1` 候选. PDF 文字、页图和公式区域进入现有聊天、回答追问及审核后 Markdown 修改流程; 不包含已退休学习工作台. 升级顺序见 [迁移说明](migration.md). 历史行为与验证记录保存在 [旧指南](history/pdf-support-through-1.1.0.md).

## 操作

1. 打开 PDF, 捕获当前阅读位置或选中文字. 无可靠页码时, 仅使用同文件最近有效位置并明确提示, 不套用另一文件的页码.
2. 展开上下文, 点击“选择 PDF 页”. 可选整页或框选区域; 区域支持拖拽和数值/键盘调整.
3. 常用组合是一张整页图加同页的一张局部图. **每轮总计最多两张图**, 整页与区域共用名额; 不能选两页后再额外增加区域.
4. 核对页码、来源和两张预览, 点击“提问”. 扫描页可依靠模型图像理解, 不会生成被宣称已核验的 OCR 文稿.

区域保留原 PDF 路径、字节版本、实际页码、归一化裁切坐标、页面尺寸/旋转及渲染缩放. 同页整图与区域的种类、图像身份和缓存元数据不同, 不伪造成两个页码. 文件变化、区域失效、缺图或模型/桥能力不足时明确拒绝; 不暗换当前页或用整图冒充原区域.

## 来源、缓存与恢复

- 文件只在客户端交给 Obsidian 内置 PDF.js 解析, 不上传整本 PDF. 每轮发送捕获的文字与最多两张 JPEG. 本地文件上限 80 MiB; 单图最长边 1600 像素, data URL 上限 1,500,000 字符; 文字与选段预算保持有界并标明截断.
- 图像为离屏重新渲染, 不包含临时选择高亮或所有非打印批注. 局部图重新渲染放大, 不是把低分辨率整图简单拉伸.
- 本设备 IndexedDB 按 vault 分区保存图像, 独立桥按配对保存. SHA-256 校验内容; scope 内去重并保留区域来源. 图像字节不放进整份聊天状态或 vault 同步文件. 分区容量保持 64 MiB 编码字节预算, 超限明确报错而不暗中驱逐原图.
- 设置可经再次确认清除页图缓存; 不清除 PDF、聊天或其他配对的数据. 在途捕获/请求时拒绝清理, 远程 epoch 防止迟到上传恢复被清缓存.
- 重发沿用原快照和图像引用. 缺少原图时必须明确重新捕获并提出新问题. 不跨设备自动合并 JPEG 缓存; 将同一 PDF 在新设备打开并不意味着已恢复旧图.
- 旧 schema 1 整页快照继续读取, 新 schema 2 区分 page/region. 区域发送依赖桥实际协商的 pdfRegions; 旧桥不伪装支持.
- 重建后台线程时, 模型输入与完整存储分开: 先选有界完整回合, 历史图片最多 8 张; 每个原请求仍最多两图. 省略内容保留来源定位和原记录, 不声称已向模型提供全部图片. 需要额外原图时明确捕获新的问题. 成功恢复已有后台线程不重复重放历史.

## 可复验样本

公开原创材料: [文字页](../examples/pdf/text-mini.pdf)、[扫描页](../examples/pdf/scanned-mini.pdf)、[密集公式页](../examples/pdf/dense-formula-mini.pdf). `scripts/create-pdf-fixtures.py` 和 `create-dense-pdf-fixture.py` 可在具备其 Python 依赖时重建; 日常构建/测试使用仓库现有样本.

本轮原生 PDF.js/canvas 检查同页整图 1236×1600、局部 1600×1179, 总两张、版本一致, 局部渲染像素倍率约 3.01. 已查看原创上下标、负号、分式和积分界; 不当作 OCR 或任意数学识别认证. 远程图像传输、能力缺失、缺图和重发有自动化回归. **本候选没有 iPad PDF 真机验收**; 细分证据见 [当前记录](reliability-suite.md).

采用宿主内置 `loadPdfJs`, 前端不静态引入 Node/Electron. API 参考为 [PDF.js 公共 API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html) 与 [官方 app-server](https://learn.chatgpt.com/docs/app-server); 实际支持仍以本机接口和能力校验为准.
