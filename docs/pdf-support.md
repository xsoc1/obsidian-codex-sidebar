# PDF 阅读与提问 (0.8.0)

文字 PDF 与扫描/照片 PDF 都接入原侧栏, 使用现有 Codex 登录、模型选择、技能、回答引用、分支重发和学习工作台. 不需要另一套聊天或 OCR 服务.

## 使用

1. 把 PDF 放入当前 Obsidian vault, 在内置阅读器打开. 展开“上下文与学习”, 点“捕获当前位置”. 文字 PDF 也可选中一段后点“解释选区”或“检查证明”. 捕获只更新卡片, 不自动发送.
2. 扫描页不需要可选文字. 无法自动定位时点“选择 PDF 页”, 选择文件, 输入实际 PDF 页码, 如 `3` 或 `3,4`, 然后“捕获并返回侧栏”. 命令面板同样提供“捕获 PDF 页”. 页码从 PDF 第一页算起, 不自动推断书内印刷页码.
3. 查看来源卡的页码、提取文本和可展开的页图预览. 页图是整页快照, 选区标明关注点, 不声称精确裁图. 确认“附带上下文”后在原输入框提问. 支持图像的模型根据页图理解扫描文字、公式与图示; 文字层不是原始 LaTeX. 密集公式或模糊扫描可能识别错误, 模型须标明不确定处.
4. 在数学工作台固定本段、解释、派生相近练习, 或明确生成 Markdown 新稿. “返回正文”定位原 PDF 页. 固定、重发和重连保留原页码/时间/文字/页图引用, 不随之后的翻页改换来源. PDF 始终只读, 不插入、替换或标注原 PDF; Markdown 新稿仍须预览和确认.

## iPad 与远程桥

插件和 Windows 桥都应更新到 0.8.0. `/info` 的 `pdfPageImages: 1` 表示支持本协议. 老桥仍可处理普通文字问答; PDF 提交前明确提示升级, 不静默丢弃页图. 电脑桥需要重新隐藏启动, 保留原 config、配对密钥与聊天状态. 无需重新配对、改 Tailscale 地址或改模型配置. 用 BRAT 选择本版本后重载 iPad 插件, 再重连. 已用正常服务的原地址升级电脑桥; 是否完成部署见本版验证记录.

原有四个折叠区保持; PDF 入口在“上下文与学习”, 写问题和发送在“提问与发送”. iPad PDF 阅读、触控选段、页图渲染和真实发送尚未真机验收; Windows 的真实请求/移动入口 fixture 不替代这项验收.

## 范围与存储

- 本地 PDF 最大 80 MiB, 每次最多两页, 每页图最长边 1600 像素, 单图 data URL 上限 1,500,000 字符. 提取文字最多 24,000 字符, 选区最多 12,000 字符, 超出明确截断; 图像不会因文字截断而被换页. 选区跨三页以上只捕获前两页并标记截断.
- 整个文件只在客户端本地交给 Obsidian 内置 PDF.js 解析, 不把整本 PDF 上传到 Windows 或模型. 模型请求只有捕获页的文字与 JPEG 图像. 无文字层不做后台全书 OCR、不生成已核验的 OCR 文稿、不读取全库资料. 加密/损坏/过大 PDF 明确失败.
- 使用宿主自带的 CMap/字体/解码资源, 不静态引入 Node/Electron. 离屏页图采用 `print` 渲染意图, 不依赖窗口动画帧. 这不是阅读器屏幕截图, 不包含临时选择高亮或未保存的交互批注; 不保证非打印批注与阅读界面完全相同.
- 页图由 SHA-256 标识. 本设备按 vault 名分区存入 IndexedDB, 不放进整份聊天状态或 vault 同步文件. Windows 桥按配对设备另存独立缓存. 各缓存分区上限 64 MiB (按编码字符串字节计), 满时明确要求清理, 不自动驱逐旧图. 同一页去重, 重启保留.
- 设置中的“清除页图缓存...”需要再次点确认, 清除本设备与已连接配对端的图像缓存, 保留 PDF、聊天和学习记录. 捕获或提问在进行时拒绝清除; 清除期间暂停新捕获与提交. 远程缓存 epoch 拒绝迟到上传. 这不撤回模型已经收到的图像.
- 缓存缺失/损坏时旧问题不能用当前页替代, 明确重新捕获后提出新问题. 不跨设备自动合并缓存; 导出学习记录只含来源/页图引用, 不包含 JPEG. 迁移前保留原设备缓存, 在新设备明确捕获新问题.
- 会话恢复最多 32 张不同页图, 超出提示新建会话, 原记录仍保留. 只恢复用户问答及来源, 不承诺完整还原进程、工具输出或模型内部状态.

## 迁移与回退

普通旧笔记和两项文字请求无需清单、缓存或新图像字段. 学习存储 schemaVersion 仍为 1, PDF 是可选来源扩展. 旧数据不增加伪页码. PDF 文件变化按二进制 SHA-256 标记关联练习版本变化, 历史尝试保留.

回退到 0.7.1 前先导出学习记录并保留原始本地数据/缓存. 旧版不理解 PDF 学习来源, 不要用旧版清除或重写这些记录. 只替换插件构建文件, 不覆盖 data.json、远程记录、配对配置或 PDF; 再升级可重新使用完整数据. 新桥兼容旧插件的普通两项请求.

公开样本是 [文字微型讲义](../examples/pdf/text-mini.pdf) 和 [纯图像扫描样本](../examples/pdf/scanned-mini.pdf), 不含私人教材. 可用 `python scripts/create-pdf-fixtures.py` (reportlab/Pillow) 重建, `node --import tsx scripts/pdf-live.ts` 是明确启动的原始材料模型检查, 需要环境变量指定 CLI 和本次原生捕获图目录, 不读取认证文件. 详见 [验证记录](pdf-validation.md).

核对依据: 安装的 Obsidian API `loadPdfJs` 声明及当前应用公开资源, [Mozilla PDF.js 公共 API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)、[官方 Codex app-server](https://learn.chatgpt.com/docs/app-server) 与本机生成 schema. API 兼容性与格式校验不认证数学正确性.
