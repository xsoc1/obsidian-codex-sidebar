# 让解释带上参数图和符号说明

捕获一段笔记或 PDF 后, 在原有提问框中输入:

> 完整解释这个例子, 附一幅可调时间 t 的参数图, 并说明符号及条件, 引用原文出处.

回答仍先给出完整 Markdown 和公式. 模型提供有效的交互数据后, 下方会出现参数图和“符号与条件”; 普通问题不强制添加卡片. [原创热方程示例](../examples/interactive/heat.md)和[矩阵交换子示例](../examples/interactive/lie.md)可用作捕获来源, 文件中的代码块也展示了交互数据格式. 旧回答仍按原样阅读, 不会后台补生成交互数据.

## 调整参数, 再带入追问

- 拖动滑块, 曲线和数值在本地更新. “重置参数”恢复模型给定的初值. 没有网络调用或自动写笔记.
- 纵轴固定, 便于比较振幅; 超范围部分裁切. 非有限值、未定义采样点会断开并显示提示. 曲线是有限采样图.
- 点“带当前参数追问”把参数和原回答引用放入提问框, 核对或补写问题后再点“提问”. 不覆盖已有草稿.
- 参数按设备、连接作用域、会话、消息及交互数据版本保存. 切换会话或重开后恢复; 不与另一设备的参数自动合并. 保存失败时仍可操作, 状态栏说明未保存或冲突.

首版支持一元 $y=f(x)$ 图、最多四个参数, 每份回答最多两幅图. 不支持模型生成的任意程序、三维应用或远程编译.

## 查看符号、使用条件和出处

点“符号与条件”中的符号查看说明. 原生 MathJax 提供准确 TeX 且与卡片唯一匹配时, 正文中的行内公式也会有点状下划线, 可点击或用键盘打开说明; 可以“返回刚才的符号”. 没有准确 TeX 元数据的渲染器仍可使用符号按钮, 不按字形猜测匹配.

来源引用须逐字匹配本轮原始快照或实际补读片段. 匹配后可“定位原文”或“打开原 PDF 来源”, 并显示映射、捕获时间、截断情况和 Windows 副本身份. 原文件变化时沿用既有版本/锚点检查, 提示变化或只打开准确文件. 重复引用、找不到原文和无文字层图像不会得到虚构定位. 引用匹配表示出处文字存在, 含义和条件仍是 AI 给出的说明.

“追问此符号”同样先填入提问框, 保留产生该回答时的原来源. 修改笔记继续使用原有“生成修改预览 → 用户确认”流程.

## 复制普通阅读版

“复制阅读版与当前参数”复制完整 Markdown、当前参数、符号说明及引用核对状态, 不带运行时控件. 复制的引用片段作为普通 text 代码块保留, 不执行其中代码. 原有复制、会话导出仍保留原回答文本和交互数据, 不暗中改变历史.

## 协议与接入

首版只需要两种组件, 采用固定的 `codex-ui` JSON 协议, 不增加 OpenUI/React 依赖. 更通用的界面语言仍可按[调研结论](research/intelligent-ui.md)另行验证.

模型在完整正文后附一个顶层代码块:

````markdown
```codex-ui
{"schemaVersion":1,"plots":[{"id":"heat","title":"衰减曲线","expression":"exp(-t)*sin(x)","x":{"min":0,"max":3.141592653589793},"y":{"min":0,"max":1},"parameters":[{"name":"t","label":"时间 t","min":0,"max":5,"step":0.1,"value":0}]}],"symbols":[{"id":"time","symbol":"$t$","meaning":"时间参数","conditions":"$t\\ge0$","quote":"设 $t\\ge0$."}]}
```
````

- 最多一个代码块, JSON 合计 24,000 字符, 最多两幅图、十二个符号. 未知字段、非法表达式、重复 ID、截断或未完整完成的回答不启用控件, 原始文本仍可阅读/复制.
- 表达式仅支持 `x`、显式参数、`pi/e`、`+ - * / ^`、括号及 `sin/cos/tan/asin/acos/atan/exp/log/sqrt/abs`. 最多 512 字符、256 token、32 层, 默认 257 个采样点. 数值范围绝对值不超过一百万. 不执行 JS/HTML, 不接收路径、工具或文件操作.
- 符号字段是 `id/symbol/meaning/conditions?/quote?`; `quote` 最多 512 字符. 解释采用受限数学 Markdown. 模型不决定真实文件目标, 宿主只使用已经保存的来源.
- 本机 Codex、独立远程桥和 API 直连沿用同一保存/重放链路. 原生整段收到完整回答后也可使用, 不依赖 SSE 或某厂商的严格结构化输出字段. Codex 每轮仍显式加载 math-writing, `turn/start` 不增加 skill 或客户端路径.
- `src/interactive/` 分别负责协议、受限 AST、绘图、来源匹配、设备状态与展示. 原始数据保存在既有消息 Text 内, 不改变会话 schema/远程协议 2. 客户端 localStorage 的 `codex-sidebar-interactive:v1:` 记录只保存参数/所选符号和组件版本.

自动化覆盖协议/截断、数学表达式、域断点、原位更新、来源歧义/PDF、设备隔离、状态重开和冲突. 浏览器与原生/模型证据分别记录在[beta.17 发布记录](releases/2.0.0-beta.17.md). 移动模拟不等于 iPad 真机; 首版 iPad 真机与各收费 API 厂商生成质量待实际验证.
