# 1.0.1 存储修复验证

日期: 2026-10-26. 用户明确授权改进存储、保留已有修改记录、修复重复错误, 然后安装 Windows 并发布 GitHub. 基线为当前 1.0.0, 未回退其他功能或变更独立远程桥.

## 复现与实现

旧版三个回归检查实际失败: 完整提案超过 200 万字符被拒绝、超过 50 条记录被拒绝、同一记录与全局错误重复显示. 原始问题的只读回放也已确认模型回复完整, 保存阶段触及上限, 未写入笔记.

生产入口改用 IndexedDB schema3. 迁移原 v1/v2 并完整回读, 保留旧键原字节; 文本快照去重, 写回目标与完整修改后文本从原任务和提案校验重建. 写入与安全撤销先提交日志, 失败不推进内存; 多窗口修订号防止旧覆盖. 容量错误的历史回复可由用户明确恢复为预览, 保留原错误历史. 无新聊天协议、技能、Node 前端静态依赖、权限扩大或工作台功能.

## 自动和浏览器检查

- 基线 `npm run build`、117 项测试通过; 候选构建与 130 项测试通过.
- 新检查包括旧数据迁移和回读、原始字节留存、超过旧容量与条数、公式和 UTF-16 选区原值、缺失/损坏文本、顺序提交、事务中断、设备作用域、多窗口旧版本拒绝、写入前零修改、确认去重、陈旧和后续编辑拒绝、安全撤销及写入/撤销后日志提交失败的恢复.
- `scripts/check-edit-storage.mjs` 在独立隐藏 Chromium 档案使用真实 IndexedDB. 原创八条提案展开为 3,277,699 字符, 索引与去重文本合计 143,732 字符. 初次迁移、旧键留存、事务中断、确认去重、安全撤销和页面重载读回通过. 单元测试另使用 fake-indexeddb, 两类证据分列.
