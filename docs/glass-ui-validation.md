## 实现

以当前 0.16.0 和本地视觉调研为基础. `CodexView` 增加局部 toolbar 容器, 会话/上下文/模型三个原有折叠区在其中布局; 输入区仍使用原有 composer. 四区的身份、存储键和节点均保留. CSS 将主题语义变量映射为磨砂背景和边缘, 模糊仅作用于 toolbar 与 composer, 正文及长历史不增加滤镜或尺寸动画.

`@supports` 为不支持模糊或混色的环境提供基础表面. `prefers-reduced-transparency` 使用不透明背景并取消模糊, `prefers-reduced-motion` 保留状态和焦点并关闭动画/按钮过渡. 未改动消息协议、上下文快照、原生 Tab/IME、私有技能和服务进程.

GitHub Actions 对 0.x 和带预发布后缀的标签继续发布 prerelease; 对 1.0.0 这样的稳定版本发布非 prerelease 并标记为 Latest. README 不再承载逐轮部署日志或哈希.
