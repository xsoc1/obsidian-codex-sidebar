# 1.1.0

- Agent 可按任务需要搜索和补读整个当前笔记库的相关内容, 保留只读、当前库和确认式写回边界.
- 长文读取支持有版本校验的分页续读; CLI 返回文字错误但退出码为 0 时, 工具不再误报成功.
- 修复 Codex 应用缓存路径只剩单个 CLI 时工具宿主无法启动的问题, 为该进程定位同目录下的完整运行包. 不混搭程序、不更改登录或全局配置.
- 插件设置新增“修改与还原缓存保留轮数”, 默认 1, 可设 N 或永不. 预览生成后按原会话后续成功完成的对话计数, 采用/还原后重新计时. 到期移除提案及还原缓存, 聊天和笔记保留.
- 写回/撤销恢复日志、冲突及未完成任务保留, 老记录不追溯清理. 计数与设备数据支持重启恢复和设备/会话隔离.

远程分页需同步更新独立 Windows 桥; 不会自动重启正在运行的旧桥. 本次 iPad 真机界面未验收.
