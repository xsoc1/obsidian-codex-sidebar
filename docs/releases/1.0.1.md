# 1.0.1

- 修改记录迁移到设备本地 IndexedDB, 相同文本快照只保存一份. 保留已有任务、提案与撤销记录, 移除原 50 条和 200 万字符限制.
- 迁移校验与回读后保留旧数据作回退副本. 存储事务失败不自动清空记录, 写入/撤销中断可核对恢复.
- 相同错误仅显示一次, 不在其他任务中重复提示. 因旧容量错误失败的完整回复可点击“恢复这次预览”, 无需再次请求模型; 仍须审核确认才能写入.

直接升级插件即可, 保留 data.json 和设备缓存. 现有兼容远程桥无需重启. 回退到 1.0.0 只能看到迁移时的旧记录, 回退前请导出新记录. 详见 [存储与恢复](../edit-storage.md).
