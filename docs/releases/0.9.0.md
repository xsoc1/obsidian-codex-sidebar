# 0.9.0 - 普通聊天确认修改 Markdown

普通侧栏聊天可直接提出笔记修改, 展示实际目标、范围、理由和差异, 明确确认后由当前 Obsidian 客户端写入/回读. 默认选区或捕获源块, 整篇需手动选择; 保留未保存草稿和撤销, 拒绝陈旧内容、重复写入及跨设备缺失基线的采用.

新增“修改选项”和独立本设备修改记录导出/清除, 不另建聊天系统或增加后台写权限. 每轮 math-writing、原快照重发、模型/档次/Fast、独立远程桥、数学最小修改规则和原生 Tab/IME 保留. 教师原题、源书摘录、PDF 继续只读. 已有 0.8.0 桥无需升级/重启.

真实模型、原生 SDK 确认按钮/未保存编辑/撤销/冲突和 fixture 分开验证. 新版 iPad 真机和日常安装尚待验收. 详见 [使用与回退](../note-edits.md) 和 [验证边界](../note-edits-validation.md). 当前文件为发布准备, 不表示已经上传 GitHub 或安装.
