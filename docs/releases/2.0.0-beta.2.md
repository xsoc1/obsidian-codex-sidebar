# 2.0.0-beta.2

长证明追问、历史恢复与长期性能改进.

- 长证明分页绑定目标正文版本, 其他消息生成不打断补读; 分隔线、列表等不再使可靠的尾部公式映射整体失效.
- 追问与恢复历史先去重再规划输入预算, 原问题、Prompt 与来源快照保持原样.
- 冲突确认持久保存决议; 最新整合说明只指向成功完成的最终回答.
- 长历史按可见消息增量刷新, 最多挂载 120 条; 优先恢复当前会话, 其他正文按需加载, 设置中支持完整会话导出.
- 流式检查点按时间/新增字节保存, 慢存储合并可替代正文. 操作事务不丢弃, 写入失败不提前公布终态. 可重读 blob 缓存有容量上限.

协议仍为 2, 新增能力单独协商. 升级应先桥后客户端; 旧桥缺少正文版本能力时长引用明确提示升级. 磁盘仅提供统计和受保护 dry-run, 不自动清理历史.

实际基线、回归、原生/真实模型证据、性能对照和设备限制见 [本轮验证记录](../reliability-suite.md). 没有本版 iPad 真机验收. 数据保留与回退见 [迁移说明](../migration.md).
