# 2.0.0-beta.16

- API 直连可关联 Obsidian 密钥，退出重开无需再填。只保存本设备的关联名称，临时输入仍只用于本次运行；取消关联不删除共享密钥。
- iPad 直连 OpenCode Go 推荐「原生整段」。启用结果显示实际传输，网络提示区分流式与整段并保留已收到的 HTTP 错误。不会自动重发请求。
- 修复流式响应复用 SSE `id` 时丢失后续正文的问题。

在支持 SecretStorage 的 Obsidian 中，选择「记住 API Key（可选）」里的密钥，再点「启用 API 直连」。没有该控件的旧版本仍支持临时 Key。此更新无需替换 beta.15 独立远程桥。

用户已在 iPad 确认 OpenCode Go / `deepseek-v4.1-flash` 的原生整段调用。新功能的重启恢复由移动构建回归覆盖；真机上的新密钥关联仍待更新后复验。见[设置与排查](https://github.com/xsoc1/obsidian-codex-sidebar/blob/2.0.0-beta.16/docs/backends.md)。
