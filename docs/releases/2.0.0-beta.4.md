# 2.0.0-beta.4

iPad 和桌面可以用自己的 API Key 直接连接 OpenAI、DeepSeek、OpenCode Go、Google AI Studio 或自定义 OpenAI 兼容端点. 在插件设置填写服务商、模型 ID 和 Key 后点击“启用 API 直连”. iPad 直连时电脑可以关机.

Windows 可在后台启动本机 Codex、Claude Code、Antigravity 或 DeepSeek Harness. Antigravity 使用官方 Python SDK; DeepSeek Harness 使用隔离的 headless 配置. API 直连和其他 Agent 复用侧栏的问答、引用及审核后写入. Key 在插件重载后需要重新输入.

BRAT 请指定 `2.0.0-beta.4`. 使用现有独立 Codex 桥的用户可以沿用原有配对, API 直连无需升级桥. 安装、权限与验证范围见 [连接方式](../backends.md).
