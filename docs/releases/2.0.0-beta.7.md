# 2.0.0-beta.7

OpenCode Go 直连启用后, 在侧栏 **模型与选项 → 思考档次** 可以选择当前模型目录提供的档次. 例如 GLM-5.3-Flash 的 `low / high / max` 与 DeepSeek V4 Pro 的 `high / max` 各自显示, 不共用固定列表.

选择 **使用服务商默认** 时不发送档次参数. 未适配的模型或服务商也显示该状态, 不再一直显示加载中. 本机 Codex 和独立远程桥的模型、思考档次与 Fast 选项不变.

BRAT 请指定 `2.0.0-beta.7`. 已配置的 Go 直连在插件重载后重新输入原 Key, 点击 **启用 API 直连**. 不需要升级远程桥. 见 [API 直连设置](../backends.md).
