# 1.0.0 - Codex Sidebar

在 Obsidian 中阅读、提问和审核笔记修改. 本版采用局部磨砂界面, 并作为 GitHub 正式版发布.

## 界面

- 顶部会话、上下文与模型工具整合在磨砂面板中, 底部输入区使用独立磨砂表面.
- 保留明暗主题、紧凑折叠、完整操作标签和连续回答阅读区. 正文不使用模糊、位移或尺寸动画.
- 不支持模糊效果时使用不透明表面; 系统选择减少透明效果或动态效果时遵循对应偏好.

## 使用

笔记与 PDF 提问、数学公式渲染、回答选段追问、会话关联与重发、行内补全, 以及修改预览、确认写回和安全撤销继续沿用现有流程. “随笔记切换会话”和“修改范围”在插件设置中调整.

README 已重写为插件功能、安装与使用指南. 历史发布和验证记录保留在 docs 与项目记录中.

## 升级

替换插件构建文件, 保留 `data.json`、远程缓存、设备记录和配对信息. 已有兼容远程桥无需重启. Codex 的读取权限及当前客户端的确认写回边界不变.

本版本发布正式渠道不代表 iPad 新界面已完成真机验收. iPad 外观、分屏和软键盘交互仍需设备确认. 详细验证见 [1.0.0 验证记录](../glass-ui-validation.md).
