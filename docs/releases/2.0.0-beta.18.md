# 2.0.0-beta.18 — 按需主动生成交互解释

捕获材料后正常提问即可, 不必每次添加“画图/卡片”的固定口令. 内置提示词按“任务约束 → 理解障碍 → 具体交互收益与数学可行性 → 最少组件”选择文字、参数图、符号说明或两者.

- 观察参数变化、衰减/频率等现象时可主动给图; 保留整数、正数等参数条件和原定义域.
- 对易混的空间/映射/对偶对象、关键条件和出处, 按需提供符号卡; 不为普通变量凑卡片.
- 尊重纯文字、短答和局部纠错要求; 修改提案 JSON、补全、翻译和纯排版不自动附组件.
- 完整正文仍先给出, 追问不机械复制上一轮全部控件. 不增加分类请求或新的协议字段.

[使用与判断规则](../interactive-answers.md). BRAT 更新需选择此确切预发布标签; 实际安装与发布状态见下文收据.

## 提示词升级与兼容

已知 beta.17 默认工作提示词精确迁移到新版. 自定义文本保持原样; 仅在尾部逐字匹配完整的旧插件托管规则时, 替换该宿主后缀, 避免旧/新交互规则叠加. 不清理自定义正文中引用或改写的旧规则. 原问题、捕获快照、消息/分支、模型/思考档次/Fast、原生 Tab/IME 与 math-writing 加载不变.

只需更新客户端. 原 beta.15 独立桥可接收客户端工作指令, 不需部署新服务或更改 approvalPolicy. 会话 schema/远程协议仍为 2, `codex-ui` 仍为 v1; 退回 beta.17 程序时保留所有新状态, 不恢复旧聊天备份. beta.17 程序可使用保存的新工作说明, 要恢复旧默认行为可在旧版设置中明确重置工作提示词. 不为回退自动覆盖用户自定义内容.

## 验证

- 原有 beta.17 构建/572项回归与组件浏览器/原生证据作为未变渲染器的基线; 本轮提示词基线14项通过.
- 新增迁移、完整宿主后缀/不透明自定义文本保护、桌面/远程/API 指令注入、补全隔离及原快照重放检查. Node24 构建和完整回归578通过、0失败、1项可选性能测试跳过.
- 真实语义样例在独立只读 Codex app-server 中执行, 正向问题不要求图或卡片, 不把预期类别传给模型; 每轮仍显式加载 math-writing. 首轮 gpt-6.1-sol / low 的6类组件选择均符合预期: 整数参数图、对偶对象符号卡、单行回答、用户禁用组件、局部追问、抽象对象不硬凑图. 图的 k 取值1—4、整数步长与三组参数下的采样值检查通过. 但符号用例没有附上可提供的原文引用, 因而来源断言失败. 增强“有对应原句即引用完整定义/条件句”后, 定向复验得到4张符号卡且4处引用逐字匹配. 共7次推理, 未重复其余已通过请求. 来源规则仅影响生成符号卡时的 quote 选择; 不把它当成已复测其他厂商模型的证据.
- 本轮没有修改渲染器/控件布局, 不重跑未受影响的截图矩阵. 收费 API 的实际选择质量和 iPad 真机仍须分别验收; 注入链路测试不冒充这些设备/服务的生成质量.

语义复验: 设置 `CODEX_POLICY_LIVE=1`、`CODEX_POLICY_CLI` 后运行 `npx tsx scripts/interactive-policy-live.ts`, 默认执行六个原创请求; 可用 `CODEX_POLICY_CASES` 选择个别样例, 追问必须同时包含原父样例. 脚本在独立临时目录保存原请求/回执/回答/报告, 不作为未知结果的自动重试入口. 常规复验使用 Node 24 的 `npm run build` 与 `npm test`.

## 安装与回退

Windows 安装只替换四个程序文件, 数据与程序分别备份; 不覆盖聊天、修改记录、草稿或其他设备状态. 独立桥保持 beta.15. iPad 在 BRAT 中指定 `2.0.0-beta.18`, API 用户继续使用已选传输方式. 程序回退及默认提示词恢复见上面的兼容说明.

本轮获用户明确安装/发布授权. 实际部署、CI 与公开资产收据以[当前维护记录](https://github.com/xsoc1/obsidian-codex-sidebar/blob/codex/reliability-suite/AGENTS.md)的日期/来源提交为准, 发布后收据提交不移动标签.
