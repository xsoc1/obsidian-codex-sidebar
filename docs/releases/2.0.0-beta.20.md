# 2.0.0-beta.20 — 就地解释、关系图与推导步骤

选中完整回答中的一段, 可直接选择 **展开这一步 / 举个例子 / 说通俗些**. 操作条临时出现在选段附近, 不挤占正文; 问题与原回答引用先放入草稿, 仍需点击“提问”. 默认先解释疑点, 再给整合后的完整说明; 已有草稿不会被覆盖.

完整回答可按需附 **关系图** 与 **推导步骤**. 点击对象查看其含义、条件及已核对的出处; 用上一步/下一步对照推导, 或针对当前节点/步骤继续解释. 完整定义、证明和结论仍先写在正文, 不依赖控件才能阅读. [使用说明](../interactive-answers.md)、[原创对偶映射示例](../../examples/interactive/duality.md).

## 协议、数据与升级

- `codex-ui` schemaVersion 1 添加可选 `relations/walkthroughs`, 复用固定组件、数学 Markdown 和来源核对. 不执行模型 HTML/JS, 不更换聊天系统或额外调用路由模型. 原有图、符号、消息快照与远程协议2保留.
- 新节点/步骤选择保存在设备本地, 重开可恢复; 旧图的参数状态键不变. 普通阅读版包含全部节点、关系、步骤和引用状态, 不只导出当前显示项.
- 精确迁移 beta.18/19 默认工作提示与完整已知托管后缀, 保留自定义文字. Codex 每轮仍显式加载 math-writing, 不添加第三个 skill 输入. 只升级客户端, beta.15 独立桥继续可用.
- 回退只替换程序, 不恢复旧整份聊天数据. 旧版不认识新组件时保留源文本供阅读/复制. [迁移与回退](../migration.md).
