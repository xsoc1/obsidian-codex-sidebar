# 2.0.0-beta.23 — 只有标准速度时收起选项

已确认模型只支持标准速度，且当前选择为标准时，「模型与选项」不再保留灰色的「速度」行。支持 Fast 或 Ultrafast 的模型仍显示可选档位。

之前保存的加速档如果不再可用，速度控件仍可用来手动切回标准，避免隐藏恢复入口。因切回标准而隐藏当前控件时，键盘焦点返回模型选择；旧远程桥的升级提示也保留。此版只调整客户端显示，不改变任何档位的实际提交、保存或独立桥兼容性。
