# 0.7.1 - 更多可折叠的 iPad 控件

会话导航和发送区现在也能收起, 为回答正文留出更多空间. 移动端四个控制区默认关闭, 各自独立展开:

- 会话与连接: 当前会话、会话列表、新会话和重连.
- 上下文与学习: 捕获/解释/检查、上下文卡和数学工作台.
- 模型与选项: 模型、思考档次、Fast、占用和补全开关.
- 提问与发送: 输入框、发送和停止按钮. 草稿保留, 标签提示“有草稿”; 点击“追问这段”会自动展开输入框.

状态、思考提示、网络错误和按需出现的引用卡保持可见. 桌面仍使用展开布局. 保留原生 Tab、中文输入法处理、原会话/来源快照和已有数学修改规则.

构建和 63 项回归检查通过. 无窗口浏览器使用相同 Obsidian 公共 CSS 对比 0.7.0, 四种尺寸的明暗主题共八组通过; 450x519 的回答区约 175->341px. 已检查折叠、草稿/选择保留、展开聚焦和发送可达. 这是 fixture, 新布局尚未经过 iPad 真机验收. 既有 0.7.0 热点基础问答成功不转算为新版布局验收.

BRAT 更新到 0.7.1 后重载插件. 保留已有 data.json、远程缓存、连接信息和学习记录. 这次没有传输/权限协议变更, 可继续使用现有 0.7.0 Windows 桥, 保留当前网络与原生请求方式. 当前电脑日常插件和正常桥未被本次发布覆盖. 如需回退, 通过 BRAT 选择 0.7.0 并只替换插件文件, 保留数据.
