# 0.13.3 - 流式回答渲染修复

回答时保留已显示的历史消息, 在离屏准备变化卡片后同步提交, 消除整段清空造成的高度塌缩和滚动回跳. 在底部时继续跟随, 向上阅读后保留位置; 公式和图片延迟排版采用同一规则. 上下文预览保留展开状态, 关闭后重开可正常恢复.

构建及 124 项测试通过. 实际 CodexView 加异步 SDK 替身的 24 个流式场景和 4 个上下文场景、12 个既有 headless 布局场景通过. 原生临时 Markdown/MathJax 组件五次更新保持历史高度 1537px, 51 个公式节点零解析错误. 未做真实模型流式或 iPad 真机验收. 诊断、复验和回退详见 [流式渲染记录](../stream-rendering.md).

用户明确授权后, 已安装 Windows 日常库并核对版本 0.13.3、七个模型和 math-writing 就绪. 八个原会话/消息/任务/快照、设置、来源/引用、设备记录、输入和折叠状态保留, 错误缓冲与基线相同. 重载后自动捕获只刷新了原快照的时间, 核对其他字段相同后恢复原快照, 完整比对通过. 主侧栏的未变刷新保留可见卡片和上下文节点, 不将其冒充真实流式请求验收.

会话、上下文、技能、设备数据与远程协议不迁移, 无需重启远程桥. 私有证据和技能不包含在安装包中. GitHub/BRAT 资产由不可变版本标签的发布流水线生成, 最终公开读回结果另行登记.
