# 1.0.3

- 在“会话与连接”中增加“删除会话”. 确认框显示会话名称、消息数量和删除边界; 取消不修改数据.
- 删除后清理对应的笔记关联、消息显示缓存和引用. 自动关联的当前笔记切换到新的空会话, 其他会话与重发分支保留.
- 删除先保存到当前设备, 失败时保留原历史; 远程同步失败会明确提示. 重启或读取旧远程快照时, 删除标记防止旧会话重新出现.
- 回复中、连接或切换中、笔记写回中以及存在未发送草稿/引用时阻止删除, 并防止重复确认.

删除会话不会修改 Markdown 笔记, 也不会清除独立保存的修改提案与安全撤销记录. 此功能不提供删除后的插件内恢复, 不代表清除服务端既有模型上下文.
