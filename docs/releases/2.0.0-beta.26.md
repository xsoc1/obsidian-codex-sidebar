# 2.0.0-beta.26 — 在侧栏浮窗预览链接

点击侧栏回答里的库内链接、「来源」或交互说明的原文按钮，就能先在浮窗查看。笔记保留 Markdown 和公式；标题、块链接只显示定位到的内容。PDF 显示链接指定的页码；点「打开原文」可以继续定位原 PDF 文字选区。关闭浮窗会返回原来的回答位置。

没有可靠的原始链接基准时，只预览能按完整路径找到的库内文件。目标已移动、锚点不存在、PDF 页码无效或 PDF 超过 80 MB 时，浮窗会说明情况。网页链接照常打开；浮窗不抓取网站。

## 复验

- `node --import tsx --test tests/sidebar-link-preview.test.ts` 检查点击路由、锚点、原标题动作、陈旧路径、完整公式和预览长度。
- `scripts/link-preview-native-probe.ts` 可打包成唯一命名的临时 Obsidian SDK 插件。使用原创笔记和 `examples/pdf/text-mini.pdf`，实测章节、Markdown 块、来源、原生 MathJax、PDF 第 2 页、关闭后焦点和滚动恢复及明确打开原文。原生布局在 680 px 和 292 px 无横向溢出；无 iPad 真机验收。
- 本地构建通过，612 项测试通过，1 项可选基准跳过。独立远程桥无需更新。
