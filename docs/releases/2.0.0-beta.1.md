# 2.0.0-beta.1

可靠会话与阅读上下文 beta. Windows 安装和独立桥升级已完成数据保留回读; iPad 需在 BRAT 中指定此版本更新.

- 问题先保存, 提交使用持久操作身份. 丢回包、短断网和桥重启只核对原操作, 未知请求不自动重发.
- 增量/分片/固定快照分页支持超过单次 4 MiB 的整体历史. 旧数据先备份和读回验证; 不同消息/设置/终态冲突保留双方.
- 回答来源固定, 支持原文回跳、重命名识别、完整数学块背景、长回答尾部精准引用及连续追问导航.
- 冷开先显示近期 40 条, 可加载旧记录. 模型重建使用有界历史和当前会话原文读取; 原 Prompt 与快照保留.
- PDF 当前页与区域放大, 同页整图/局部图合计最多两张. 修改卡片显示中文状态、实际行范围和缓存剩余轮次.
- 本地草稿、准备取消、环境检查与普通分支/PR 的 Windows/Ubuntu Node 24 CI.

Windows/Node 24.17.0 构建和 245 项自动化通过. 原创材料的一次真实 `gpt-6.1-sol / low` 请求成功调用历史读取, 桥重建后仅只读恢复. 原生 PDF/Markdown 组件、SDK 性能与 CI 分级记录见验证说明; iPad 真机、物理 IME、实际锁屏/切网仍待复验.

先升级独立桥, 再升级同一配对的客户端. `math-writing` 仍是外部私有依赖, 包内不含技能或个人数据. 兼容、数据保留与回退见 [迁移说明](https://github.com/xsoc1/obsidian-codex-sidebar/blob/2.0.0-beta.1/docs/migration.md), 完整结果见 [验证记录](https://github.com/xsoc1/obsidian-codex-sidebar/blob/2.0.0-beta.1/docs/reliability-suite.md).
