# 2.0.0-beta.17 — 参数图与符号定位

## 使用

捕获笔记/PDF 后, 请求“完整解释, 附可调参数图及符号/条件说明”. 新回答可展示本地滑块曲线和有来源核对的符号说明. “带当前参数追问”或“追问此符号”先填入草稿, 用户再发送. 原文、公式和主要证明保持完整.

- 参数按设备/连接/会话/消息/组件版本保存, 支持重置及复制普通阅读版.
- 原生 MathJax 的精确符号可点选, 支持键盘与返回符号位置; 无准确元数据时保留按钮入口.
- 来源不明、重复或纯图像识读不会伪造文字定位. 文件变化沿用原版本/锚点检查.
- 复用现有后端、会话和修改预览; 无新增框架、推理服务或任意模型代码执行权限.

[使用与协议](../interactive-answers.md)。BRAT 请明确选择 **2.0.0-beta.17**.

## 复验入口

使用 Node 24 运行 `npm run build`、`npm test`. 浏览器闭环运行 `node scripts/check-interactive-ui.mjs`, 需设置 `CODEX_LAYOUT_BROWSER` 与 `CODEX_LAYOUT_APP_CSS`, 自动创建独立临时 profile/来源并保存报告/截图. 它模拟 SDK/Markdown 边界, 不操作日常 Obsidian.

真实请求脚本为 `scripts/interactive-live.ts`, 需显式设置 `CODEX_INTERACTIVE_LIVE=1` 和 `CODEX_INTERACTIVE_CLI`; 每次调用会提交一次新的原创请求, 不作为恢复或常规测试. 原生导出函数为 `scripts/interactive-native-probe.ts`, 由唯一测试插件加载, 使用自建原创笔记及可回收 Modal; 日常会话不作为测试材料.
