# 0.10.0 - AI 自选范围与桌面折叠

- 普通聊天默认由 AI 选择当前笔记中的一段修改范围. 模型返回精确原文, 客户端唯一定位、检查只读范围、展示实际原文/差异, 确认后才写入. 可切回严格选区; 旧任务重发保持原方式. 长笔记只提供附近 24000 字符窗口, 不跨文件.
- 独立“笔记选中内容”卡片直接显示选区, 保留公式源文、映射、截断及附带状态. 转到聊天输入不会悄悄换掉选区; 卡片可折叠或清除.
