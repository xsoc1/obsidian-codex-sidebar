# 2.0.0-beta.13

- 统一引用、笔记与 PDF 图文材料：预览、草稿恢复和实际发送使用同一份材料；追问旧回答时可另附新的 PDF 条件，分别移除。上下文可展开查看解释背景、截断与缺失；PDF 文字选区可显式补充同页图像。
- API 直连支持 Fetch SSE 流式回答，明确区分完整、部分、拒绝、未知等结果。部分回答可主动继续；停止等待不冒充取消服务端请求，迟到结果按原操作保留，不自动重复提交。
- 长引用使用受限、版本检查的历史读取或有界预取；新增不含密钥的命名连接配置，切换连接、模型和思考档次保持实际请求协议与快照一致。
- 修复异步保存确认与重试；因果冲突裁定保留双方证据和确切前序决定；桥的大文件读取改为真正的有界范围读取，避免每一分片重读整文件。

## 升级

BRAT 请指定 **2.0.0-beta.13**。独立远程桥应先更新到本版，再升级同配对的客户端，以使用新的因果冲突裁定；协议仍为 2。保留原数据目录、HTTPS 入口和配对密钥，无需重新配对。API 直连和本机 Codex 不需要远程桥。

升级前备份插件、会话/操作证据、设备缓存与修改数据库。只替换程序，不能用旧整份备份覆盖新增记录。旧客户端不理解新因果决议时不得继续写回。详见 [迁移与回退](../migration.md)。
