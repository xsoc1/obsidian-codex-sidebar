# 0.8.0 - PDF 页面提问

文字层 PDF 与扫描/照片 PDF 接入现有侧栏. 可解释选段、捕获当前页, 或通过“PDF 页...”明确指定一到两页. 来源卡保留页码、时间、文字、截断与可预览的页图; 扫描页由支持图像的 Codex 模型识读. 原生 PDF 文件只读, 可复用伴读与练习、审核后生成 Markdown 新稿.

重发、分支、重连恢复原页图; 缺图明确拒绝, 不换成后来翻到的页. 图像缓存独立于聊天和同步状态, 本设备/远程配对设备隔离、哈希校验、去重及确认清除. 四个移动折叠区、具体模型/档次/Fast、math-writing、原生 Tab、IME 和已有数学修改规则保留. 顺带修复重连取消后台状态保存时的未处理异步错误.

用 BRAT 更新插件并重载. PDF 需要 Windows 桥同升 0.8.0 后重连; 旧桥的普通文字问答仍兼容. 不覆盖配对密钥、会话、学习数据或 PDF. 无需另装 OCR 或申请 API key. 有界捕获不上传整本书; 上限及回退见 [使用指南](../pdf-support.md).

原生 Obsidian 的实际离屏提取、图像渲染/缓存与独立真实 Codex 扫描问答、桥重启图像历史恢复、文字页练习输出已分别验证. 一次练习请求遭遇服务端 429, 单独重测成功. 新功能尚未通过 iPad PDF 真机验收; 页码 DOM、移动流程与安全拒绝由 fixture 检查, 不冒充原生点击验收. 详细证据范围见 [验证记录](../pdf-validation.md).
