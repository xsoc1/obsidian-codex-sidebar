# 0.13.0 - 提问与修改预览分开

- 删除“本轮方式”和“原文类型”选项. 原发送按钮改为固定的“提问”和“生成修改预览”, 保留停止.
- Enter 固定提问, Shift+Enter 换行, 原生 Tab 和中文 IME 保留. 不再根据输入关键词自动决定改稿.
- 原文类型交给 AI 根据片段和请求辨识, 保留最小修改、原证明路线、语言风格和只读边界. 修改范围仍可选, 预览仍须审核确认后写入.
- 保留历史任务、来源快照、重发/分支、模型选择、折叠、独立远程桥与设备隔离. 引用助手回答时预览按钮暂停, 取消引用后恢复.

构建和 119 项 fixture、12 组 headless 布局、一次原创材料真实 Codex 请求通过. 模型改稿的写入检查采用内存宿主. 经明确授权安装 Windows 日常库, 原生主侧栏按钮/合成键盘/引用保护和明确路由通过拦截式检查, 截图已查看; 六个原会话、快照、设置和设备记录保留. iPad 本版与人工 IME 未验收. 详情见 [使用、迁移与验证](../explicit-compose.md).

升级保留 data.json、配对信息和设备本地存储; 在用远程桥无需重启或改配置. 发布后可通过 BRAT 检查此预发布版本.
