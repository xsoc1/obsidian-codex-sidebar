- 删除“本轮方式”和“原文类型”选项. 原发送按钮改为固定的“提问”和“生成修改预览”, 保留停止.
- Enter 固定提问, Shift+Enter 换行, 原生 Tab 和中文 IME 保留. 不再根据输入关键词自动决定改稿.
