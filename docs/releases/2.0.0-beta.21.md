# 2.0.0-beta.21 — 更新内置数学写作规则

- **问答先讲明白。** 默认先用常用词说清结论或核心直觉，必要时给一个短例子。用户要求详细推导时照常展开；讲义、证明和改稿遵守原来的文体、严谨度和修改范围。
- **正文与交付说明分开。** 数学假设、反例和未闭合的证明步骤留在相关推导旁。来源核对范围、实际验收和交接事项在需要时另说。“生成修改预览”把具体修改依据和必要的交接事项放在预览理由里，确认仍只写用户审核的正文，不自动另建说明笔记。普通问答不附固定说明块。

两项变化来自本机核对的 math-writing `0.3.0-candidate.6`，适配到插件的公开内置提示。没有随包分发私有技能；本机和远程 Codex 仍显式加载运行主机启用的技能，API 直连使用内置快照规则。只需升级客户端，现有 beta.15 独立桥可继续使用。已知旧默认提示和完整旧托管后缀精确升级，自定义内容、旧问题和来源快照原样保留。[迁移和回退](../migration.md#beta21-数学写作规则)
