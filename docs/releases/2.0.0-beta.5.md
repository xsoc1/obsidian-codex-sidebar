# 2.0.0-beta.5

在 Windows 或 iPad 的 Codex Sidebar 设置中选择 API 服务商, 填入 Key, 点击 **加载模型**. 从 **上游模型** 选择后点击 **启用 API 直连**. OpenCode Go 可以先加载公开目录再填 Key; OpenAI、DeepSeek、Google AI Studio 和自定义 OpenAI 兼容服务使用各自的模型列表接口.

读取目录不会发起推理, 也不会改动当前连接. 目录不代表账号权限, 服务商不提供列表时仍可手填模型 ID.

BRAT 请指定 `2.0.0-beta.5`. 仅更新插件程序, 保留原有会话与设置; 不需要更新或重启独立远程桥. 详见 [API 直连设置](../backends.md).
