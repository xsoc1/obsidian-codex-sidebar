# 0.11.0 - 公式对照与按笔记会话

- 修改提案默认显示可排版的“原文 / 拟采用稿”, 行内与行间公式保留完整边界. 原始字符差异仍可展开, 显示上下文不会扩大实际写入范围; 排版不再阻塞确认控件.
- Windows 原生笔记切换检测已验证, 新增默认开启的“随笔记切换会话”. 为 Markdown/PDF 分别创建和恢复会话, 可手动绑定旧会话, 保留所有原历史; 手动关闭后记住选择. 回复/草稿/引用/作答/写回期间延迟到安全时点, 只跟随最后目标.
- 关联仅存当前设备并区分桌面/远程 scope, 不上传关联表, 不扫描全库或自动请求模型. 重命名保留关联, 删除保留历史; 只读、确认写回、模型选择、原始快照和重发语义不变.

已通过 build/106 项 fixture, 原生公式组件/文件事件及明暗/窄栏 headless 已分层核对. 经明确授权安装到 Windows 日常库, 实际主侧栏 A→B→A、草稿延迟与重载恢复通过; 旧聊天、原快照、设置和学习/修改记录保留. 本版通过 GitHub 预发布供 BRAT 获取; iPad 本版真机未验收. 详见 [使用、迁移与验证边界](https://github.com/xsoc1/obsidian-codex-sidebar/blob/codex/initial/docs/formula-comparison-and-note-sessions.md). 现有远程桥无需升级.
