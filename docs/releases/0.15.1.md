# 0.15.1 - 发送区避让底部状态栏

修复展开“提问与发送”后, 提问/生成修改预览/停止按钮被 Obsidian 底部状态栏盖住的问题. 根据当前窗口的实际交叠预留底部空间, 状态栏隐藏或不相交时恢复紧凑布局. 状态栏高度变化、移除和重建均可更新; 关闭侧栏会取消观察器和排队回调. 不改变全局状态栏样式或聊天数据, 无数据迁移.

原因已在原生 Windows 重现: 0.15.0 的底部留白为 12px, 当前悬浮状态栏高 27px, 三个操作有约 13px 被覆盖, 侧栏已无法继续下滚. 仅增加局部留白即消除遮挡. 旧 headless 布局未包含外部状态栏, 其通过不能证明这个场景安全.

基线与候选构建/127 项测试通过. 28 个既有布局场景通过; 新增 4 个外部状态栏明暗/240px 与 540px 场景先失败后通过, 覆盖 27/48px 高度、隐藏/恢复、不相交、移除/重建与清理. 24 个实际 CodexView 流式 SDK fixture 和 4 个上下文场景通过. 这些不是本版真实模型回复或 iPad 真机验收. 在用远程桥无需重启, iPad 可仅更新客户端.

已按本次授权安装 Windows 数学库, 四件资产与构建相同. 原生展开提问区实测: 自动测得 27px 交叠, 底部总留白为 39px, 按钮底边 918px、状态栏顶边 932px, 三个按钮均无覆盖; 已查看实际窗口截图. 检查后恢复原开合与滚动位置, 20 个原会话及消息/任务/来源、设置、设备存储、草稿/折叠状态核对保留, 七个模型与技能正常, 错误缓冲不变. 未发送新模型请求或改笔记/全局状态栏/私有技能/在用远程桥.
