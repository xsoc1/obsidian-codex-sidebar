# 修改记录存储与恢复

1.0.1 将修改记录从 localStorage 中的单份大型 JSON 迁移至设备本地 IndexedDB. 不改变聊天协议、模型、技能、权限或远程桥; iPad 的记录与写入仍属于 iPad 客户端.

## 保留与迁移

- 第一次打开时读取本设备旧 v2, 没有 v2 时读取可支持的 v1. 校验原任务、来源、全文基线、实际范围、提案和写回状态后, 以一个事务写入新存储, 再回读比较所有值. 迁移不写笔记.
- 迁移成功后保留旧键的原始字节. 后续重新打开以新存储为准, 不把旧备份或远程聊天状态覆盖到它上面. 发现未知版本或损坏内容时拒绝使用, 不静默重建空库.
- schemaVersion=3 的内部索引保留任务与写回元数据. 文本以 UTF-16 码元的 SHA-256 摘要去重, 保留原始换行、公式、选区和时间; 加载时校验文本摘要. 写回目标和修改后全文从原始任务及经校验的输出重建, 仍需通过完整的修改范围校验.
- 不再有 50 条或 200 万字符的插件硬上限, 不自动淘汰记录. 实际可用空间仍受设备与 WebView 配额限制, 可定期导出备份.

同一设备内按 vault 名称隔离, 延续旧存储的作用域. 不自动合并不同设备记录, 不上传原文基线, 不更改远程设备身份. 同一作用域的多个窗口通过修订号检查防止旧窗口覆盖新记录; 冲突时重载插件后再操作.

## 写入与撤销

所有变更顺序提交, 事务完成前不推进内存状态. 同一事务更新索引与文本, 并清理失去引用的文本, 保存仍被旧记录使用的快照. 存储失败不会自动清空历史.

确认写入先持久化 pending 日志, 再由 Obsidian 客户端比较当前内容、写入并回读, 最后保存 applied. 若笔记已写入而最后的完成日志保存失败, 会明确提示; 存储恢复后再次确认只核对结果, 不重复写入. 撤销同样先保存 UndoPending, 中断后仅在当前内容仍是原稿或修改稿时恢复; 发现后续编辑仍拒绝覆盖.

未知操作、陈旧基线、重复定位、中断模型输出和缺失本设备原文继续拒绝采用. Codex 保持只读, 只有客户端中的确认按钮能写入.

## 恢复旧容量错误

旧记录中的容量错误仍保留, 每条仅显示一次. 若原会话保存了完整回复, 该提案旁显示“恢复这次预览”. 点击后读取原 TaskSpec 和回复, 保留错误历史, 重新生成供审核的差异. 不切换到当前选区、不重新调用模型、不自动采用.

缺少完整回复或回复中断时拒绝恢复. 即使成功生成预览, 当前笔记已变化时仍须重新捕获后提出新修改.

## 导出、清除与回退

插件设置中的“导出记录”继续导出完整展开的 schemaVersion=2 JSON, 包含原始基线和记录, 请自行保管. 当前没有导入界面. 用户二次确认清除时清空新存储与旧回退副本, 但保留必要的待确认写入/撤销日志. 笔记和聊天保留; 已清除的旧提案不能再采用或安全撤销.

升级只替换四个插件构建文件, 保留 data.json、设备缓存和配对信息, 无需重启现有兼容桥. 回退到 1.0.0 会读取迁移时留下的旧 v2 副本, 看不到迁移后的新记录; 不会自动撤销已采用的笔记. 回退前先导出新记录, 并处理所需安全撤销. 旧版再次编辑后产生的旧副本变化不会自动合并回新版. 原有 Windows 安装与原生检查另见验证记录; 本版 iPad 真机迁移未验收.

## 复验与依据

`npm run build` 与 `npm test` 检查迁移、去重、容量边界、事务失败、并发窗口、记录恢复和写回安全. `CODEX_LAYOUT_BROWSER=<Chromium 路径> node scripts/check-edit-storage.mjs` 使用独立浏览器档案及原创材料检查真实 IndexedDB 和页面重载; 不连接模型或日常 vault.

事务字段按 [MDN transaction](https://developer.mozilla.org/en-US/docs/Web/API/IDBDatabase/transaction) 与 [IndexedDB 事务](https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction) 核对. 请求 strict durability, 以 complete 判定事务完成, abort 拒绝提交. 实际配额仍遵循 [Web 存储限制](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria). 单元测试的 [fake-indexeddb](https://github.com/dumbmatter/fakeIndexedDB) 是内存测试替身, 不代替真实浏览器或 iPad 验收.
