# 数学表达专项：验证记录

## 程序与原功能

- 基线 `npm ci`、`npm run build`、`npm test` 实际执行, 106 项测试通过。
- 候选构建与 113 项测试通过。新增覆盖精确旧默认迁移、自定义及引用保留、客户端/桥端幂等、实际服务端环境、字段分工、原创夹具与评分隔离、快照重发、短补全策略及明确语言修改的路由。
- 现有测试继续覆盖技能缺失、公式和截断、回答引用、补全与 IME/原生 Tab、作答抑制、确认前零写入、去重/陈旧/安全撤销、设备隔离、PDF 图片边界、存储恢复和旧数据迁移。这些是 fixture/受控测试结果, 不转算为真机或数学证明。

## 真实模型对照

输入和评分条件分开保存。开发样本 D02/D04/D08/D14 各有基线与候选请求, 冻结之后 H01–H08 各有成对请求。模型固定 `gpt-6.1-sol`, `low`, Fast 关闭/`serviceTier=default`, 临时只读会话, 每次输入 text+实际发现的 math-writing。

24 个输入夹具均做程序检查; 12 个成对场景实际生成。完整生成、失败和修订结果保存在本地证据目录, 不自动进入公开 Git。随机顺序展示用于作者核读; 输出自身含版本线索, 不能称严格盲评。本轮核读者为实现者 AI, 没有独立人工审查或学生学习效果测试。

| 场景 | 数学/范围检查 | 表达观察 |

## 技能候选与编码修订

生产技能仍为用户安装的 0.2.0。测试入口只选择 `skills/list` 在自有测试根实际返回的同名 repo 技能, 记录实际路径、入口版本与文件树摘要; 未放宽生产的用户级优先选择或远程路径校验。

candidate.1 调整表达与路由, candidate.2 增加 UTF-8 文件读取说明。两版样章均报告参考文件乱码, 结果保留。candidate.3 增加当前进程输出编码说明后运行完整留出集。命令日志表明实际 Codex 通道仍有乱码, 因而未将本机管道成功冒充工具通道修复。

本机受控测试中, 显式输入/输出 UTF-8 可逐字恢复原文件; 实际 Codex 日志却仍出现替换字符。ASCII JSON 读取在同一 bundled PowerShell 中往返逐字一致。最终 candidate.4 只增加该读取方法, 不修改数学/表达规则, 再单独复测 D04。实际 Codex 的最终读取命令输出全为 ASCII、替换字符为零; 四个 JSON 字符串解码后分别与 intro-lecture、exposition、pedagogy、typesetting 源文件逐字一致, 样章完整且不再声称参考文件未读。前两次读取失败及原输出仍保留。完整留出生成对应 candidate.3, 不冒充 candidate.4 全量复跑。

技能创建器校验首次因 bundled Python 缺 PyYAML 无法启动; 在证据目录安装局部依赖后实际通过, 未改全局 Python 或技能安装。私有补丁与候选包和插件包分开交付。

## 复现入口与边界

`scripts/exposition-live.ts` 读取以下显式环境变量: `CODEX_EXPOSITION_CLI`、`CODEX_EXPOSITION_EVIDENCE`、`CODEX_EXPOSITION_BASELINE`。证据根下先准备 `baseline-workspace` 和 `candidate-workspace`, 各自是独立测试仓库, 技能位于自身 `.agents/skills/math-writing`。原始材料仅来自本仓库的原创夹具。

- 默认 stage=discover, 只核对发现与固定模型/档次, 不推理。
- stage=development 默认四组; stage=holdout 要求开发结果和作者核读记录齐备, 两个变体完整执行。
- `CODEX_EXPOSITION_RUN` 绑定不可覆盖的冻结与输出; 显式开发修订可用 `CODEX_EXPOSITION_IDS` / `VARIANTS`, 不允许过滤留出集。重复未决请求不会自动重发。
- `scripts/exposition-review.ts` 生成随机顺序对照, 不自动评分。`exposition-remote-live.ts` 需要单独 `CODEX_EXPOSITION_REMOTE_LIVE=1`, 只发送一条原创问题。
- 单独运行 `exposition-native-probe.ts` 的临时插件, 不能替换日常插件。人工输入及截图验收留待有相应环境和授权时进行。

插件 candidate 0.12.0 与私有技能候选均未正式安装或发布。安装前备份被替换资产, 保留 data.json、设备存储与配对; 回退只处理本次资产及未被后续编辑的迁移字段。公共仓库只保存原创样本、代码和匿名总结。
